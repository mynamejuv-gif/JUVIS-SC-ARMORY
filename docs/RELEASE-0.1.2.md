# Version 0.1.2 — JUVIS launcher icon

Adds a silver star-and-laurel JUVIS emblem with cyan accents, inspired by the supplied reference. The original generated PNG is included in `src/Juvis.Android/Resources/drawable-nodpi/juvis_emblem.png`. An adaptive Android launcher icon supplies padding for launcher masks. Version code is 3.
